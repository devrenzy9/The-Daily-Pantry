# The Daily Pantry

Grocery e-commerce app built with React, Vite, Tailwind, and Express.

## Stack

Frontend:
- React
- Vite
- Tailwind CSS
- GSAP

Backend:
- Express.js
- JSON file storage
- UUID

## Features

- Product listing
- Cart management
- Order creation
- Newsletter subscriptions
- Responsive UI

## Run locally

```bash
npm install
cd server && npm install
npm run dev:full
