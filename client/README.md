# 🛒 The Daily Pantry - Grocery Landing Page

A feature-rich **grocery store landing page** built with **React, Tailwind CSS, and GSAP**.  
This project showcases a **modern e-commerce UI** with interactive elements, smooth animations, and a premium shopping experience.

---

## 🚀 Features

- **Interactive Navigation**
  - Responsive navbar with category dropdowns
  - Mobile-friendly drawer menu
  - Sticky header on scroll

- **Dynamic Product Display**
  - Product cards with hover effects
  - Category filtering
  - Deal and discount badges
  - Star ratings display

- **Special Sections**
  - Hero banner with call-to-action
  - Daily deals countdown timer
  - Popular products grid
  - Category browsing
  - Newsletter subscription

- **Smooth Animations**
  - GSAP scroll-triggered animations
  - Product card hover transitions
  - Section entrance effects

- **Fully Responsive**
  - Desktop, tablet, and mobile optimized
  - Touch-friendly interface

---

## 🛠️ Tech Stack

- **React.js** — UI framework
- **Tailwind CSS** — styling & responsive layout
- **GSAP** — scroll + hover animations

---

## 📂 Setup & Run Locally

1. Clone the repo:

    ```bash
    git clone https://github.com/devrenzy9/The-Daily-Pantry
    cd Grocery-Store-Landing-Page
    ```

2. Install dependencies:

    ```bash
    npm install
    ```

3. Start the development server:

    ```bash
    npm run dev
    ```

4. Open [http://localhost:5173](http://localhost:5173) (or the port shown in your terminal).
